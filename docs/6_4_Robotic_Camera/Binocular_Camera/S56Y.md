# Astra S56Y Stereo Camera

## Overview

S56Y is a new-generation YUV stereo camera for embodied intelligence and data collection applications. Two ST VB1940 color Global Shutter sensors and built-in ISP processing provide 2400(H) × 1800(V) @ 30fps YUV422 8bit output per eye. Its lens provides a 128° horizontal and 91° vertical field of view. Compared with S56D, selection differences include built-in image processing, output format and field of view.

The design combines a 60 ± 0.5mm stereo baseline, precision stereo active alignment (AA), a TDK ICM-45686 six-axis IMU and GMSL2. Standard and lightweight housings and connector options are available.

### I2C and Control Signals

| Component | I2C address | Control signal |
|---|---|---|
| MAX9295D | 0x80 (8bit) | GMSL2 6Gbps |
| Sensor 0 | 0x20 | MAX9295D MFP7: frame sync |
| Sensor 1 | 0x20 | MAX9295D MFP7: frame sync |
| MCU | 0x64 (8bit) | MAX9295D MFP7: frame sync |
| EEPROM (Sensor 0) | 0xA1 | As listed in the datasheet |
| EEPROM (Sensor 1) | 0xA0 | As listed in the datasheet |
| ISP | 0xDA (8bit) | MAX9295D MFP0: reset |

The MCU is listed as **0x64 (8bit)**, corresponding to the **7bit address 0x32**. Other addresses follow the latest English datasheet. It lists EEPROM addresses as 0xA1 / 0xA0 without specifying the read/write-bit or alias convention. Confirm how each EEPROM is addressed, along with the 7bit / 8bit convention, dual-sensor addressing and SerDes mapping for all devices. Use the supplied configuration for synchronization timing, reset and initialization.

### Stereo Calibration and Parameter Access

Factory calibration covers stereo camera intrinsics / extrinsics and IMU intrinsics / extrinsics. Stereo calibration uses the **Omni-Radtan** model; consumers must use a matching model. Read calibration with SENSING sgMIX or parse it using the SENSING stereo camera OTP data format specification.

Use the factory calibration for the individual device. Nominal mechanical transforms describe the design geometry and do not replace device calibration. Calibration from S56 / S56C / S36 must not be reused directly.

## Camera Usage {#platform-integration}

### Integration with Custom Platforms

1. Check the GMSL2 6Gbps deserializer, connector option, power requirements and I2C mapping. Obtain the initialization and synchronization settings for this model.
2. Initialize the SerDes link and configure host capture for each eye (2400(H) × 1800(V) @ 30fps, 8-bit YUV422). Apply the supplied frame synchronization settings.
3. Verify left/right ordering, image orientation, frame synchronization and IMU data. Read the calibration for the individual device.
