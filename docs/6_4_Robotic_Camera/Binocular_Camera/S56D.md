# Astra S56D Stereo Camera

## Overview

S56D is a new-generation RAW stereo camera for embodied intelligence and data collection applications. Two 5MP color Global Shutter sensors each output 2560(H) × 1984(V) @ 30fps in RAW10, for vision systems that process RAW images on the host. The lens provides a 140° horizontal and 102° vertical field of view.

The design combines a 60 ± 0.5mm stereo baseline, precision stereo active alignment (AA), a six-axis IMU and GMSL2. Standard and lightweight housings and connector options are available.

## IMU and Stereo Calibration {#imu-and-calibration}

### IMU Parameters

| Parameter | Value |
|---|---|
| IMU | Six-axis IMU |
| Accelerometer range | ±16g |
| Gyroscope range | ±2000°/s |
| Output data rate | 200Hz |

### Stereo Calibration and Parameter Access

Factory calibration covers stereo camera intrinsics / extrinsics and IMU intrinsics / extrinsics. Stereo calibration uses the **Omni-Radtan** model; consumers must use a matching model. Read calibration with SENSING sgMIX or parse it using the SENSING stereo camera OTP data format specification.

Use the factory calibration for the individual device.

## Camera Usage {#platform-integration}

### Integration with Custom Platforms

1. Check the GMSL2 6Gbps receiver, connector and power requirements. Obtain the integration and synchronization settings for this model.
2. Set up the GMSL2 link and configure host capture for each eye (2560(H) × 1984(V) @ 30fps, RAW10). Apply the supplied frame synchronization settings.
3. Verify left/right ordering, image orientation, frame synchronization and IMU data. Read the calibration for the individual device.
