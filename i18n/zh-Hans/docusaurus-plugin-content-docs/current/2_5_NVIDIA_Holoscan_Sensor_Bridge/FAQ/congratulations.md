# HSBKITxM 常见问题

本文汇总了 HSBKITxM 产品相关的常见问题，可用于排查使用 HSBKITxM 时遇到的问题。


#### 摄像头无法工作

**Q1**: 驱动安装后摄像头无法显示图像怎么办？

1. 检查摄像头是否正确连接
2. 确认已选择正确的摄像头型号和端口
3. 使用 `dmesg | grep -i max` 检查驱动是否已成功加载

#### 系统性能问题

**Q2**: 运行多路摄像头时系统性能下降怎么办？

1. 检查散热是否充足
2. 使用 `sudo jetson_clocks` 命令固定时钟频率以获得最佳性能
