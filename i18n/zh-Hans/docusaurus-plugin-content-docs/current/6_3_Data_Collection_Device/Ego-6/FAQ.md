# Ego-6 常见问题

## 连接与预览

### 上位机连不上设备怎么办？

1. 确认设备已扣上电池、侧面电源指示灯已亮起。
2. 确认 Type-C 数据线已连接，且在 Windows 网络设置中能看到「未识别的网络」虚拟网口。
3. 确认该网口已手动配置同网段 IP（如 `192.168.140.21`，子网掩码 `255.255.255.0`）。
4. 确认 EGOTool 中设备 IP 为 `192.168.140.20`、端口为 `58889`，再点击「设备连接」。

详见 [使用说明 · 连接 EGOTool 上位机](/zh-Hans/docs/6_3_Data_Collection_Device/Ego-6/User_Manual#连接-egotool-上位机)。

### 预览画面忽明忽暗或卡顿？

这是电脑端实时解码跟不上导致的，**不是设备故障**。实时预览仅用于确认画面，数据以 SD 卡上的录制文件为准，录制不会因此丢帧。

### 如何确认设备已开机？指示灯颜色代表什么？

指示灯位于机身右侧录制按键旁，亮起即表示设备已上电开机：

| 指示灯颜色 | 状态 |
|-|-|
| 紫色 | 正在录制 |
| 白色 | 已结束录制 |

## SD 卡与录制

### 插卡后不录制，或上位机看不到 SD 卡剩余空间？

多半是**假卡或不兼容卡**导致：

- 换用实测可用的卡：**移速（MoveSpeed）A1 V30**、**Biwin** 等；
- 上机前先用 **H2testw** 验证真实容量；
- 将 SD 卡格式化为 **exFAT**，容量建议 ≤ 256 GB。

部分 SanDisk A1 / V10 消费级卡已知无法在本设备上工作。

### 如何正确关机 / 断电？

**先结束录制，待录制停止并保存后，再取下电池。** 切勿在录制过程中直接断电，以免丢失数据。

### 设备充不进电？

电池电量**特别低**时，直接用 Type-C 充电器连接设备无法充电。请将磁吸电池取下，使用**电池充电配件**单独充电。电池满电续航约 3 小时。

### 录制的文件很长，回放卡顿、占用内存高？

建议单个文件录制时长短一些，或按场次分段录制。

## 数据查看

### Foxglove Studio 打开文件后没有画面？

- 打开文件后主界面为空是正常的，需要导入布局文件 `Ego-Foxglove-Layout.json`（右上角布局按钮 →「从文件导入……」），或手动添加图像面板；
- 确认打开的是 `.mcap` 文件本身；
- 确认 Foxglove Studio 为较新版本（支持 H.265 解码）。

详见 [使用说明 · 使用 Foxglove Studio 查看录制文件](/zh-Hans/docs/6_3_Data_Collection_Device/Ego-6/User_Manual#使用-foxglove-studio-查看录制文件)。

### 可以用 VLC 等普通播放器打开录制文件吗？

不可以。`.mcap` 是多传感器数据容器格式，不是普通视频文件，请使用 Foxglove Studio 查看。

### 什么是 MCAP 文件？

MCAP 是由 Foxglove 推出的开源、面向机器人/自动驾驶领域的模块化容器文件格式，用于把多路相机图像、IMU 等传感器数据按时间戳打包存入同一个文件，便于回放与分析。它与 ROS bag（`.bag` / `.db3`）用途类似，但读写性能更好，C++ / Python / Rust / Go 均有官方 SDK，也是 ROS 2 rosbag2 的默认存储格式。

Ego-6 采集结束后得到的 `.mcap` 文件，就是这段时间内设备看到和感知到的全部数据，可用 Foxglove Studio 打开，用于算法调试、数据标注与问题复现。

## 术语

| 术语 | 说明 |
|-|-|
| **Egocentric（第一人称）采集** | 从佩戴者的第一视角进行数据采集。 |
| **MCAP** | Foxglove 原生支持的多传感器录制容器格式，自带消息 schema。 |
| **IMU** | 惯性测量单元，本设备用于记录头部姿态。 |
