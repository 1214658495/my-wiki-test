# S36A 双目摄像头

## 概述

S36A 是面向具身智能与数据采集应用的新一代 HDR 双目摄像头，采用两颗 Sony ISX031 彩色卷帘曝光传感器和内置 ISP，支持 140dB HDR，每目可输出 1920(H) × 1536(V) @ 30fps 或 1920(H) × 1080(V) @ 60fps YUV422 图像。

采用 60 ± 0.5mm 双目基线、高精度双目 AA 工艺、TDK ICM-45686 六轴 IMU 和 GMSL2 接口。提供标准版、轻量化版及不同连接器配置。

### I2C 与控制信号

| 器件 | I2C 地址 | 控制信号 |
|---|---|---|
| MAX9295D | 0x80 (8bit) | GMSL2 6Gbps |
| Sensor 0 | 0x34 | MAX9295D MFP7: frame sync; MFP1: reset |
| Sensor 1 | 0x36 | MAX9295D MFP7: frame sync; MFP2: reset |
| MCU | 0x64 (8bit) | MAX9295D MFP7: frame sync |
| EEPROM (Sensor 0) | 0xA1 | 按规格书列出 |
| EEPROM (Sensor 1) | 0xA0 | 按规格书列出 |

MCU 统一以 **0x64（8bit）** 列出，对应的 7bit 地址为 **0x32**。其余地址按最新英文规格书列出。EEPROM 地址在源文件中标为 0xA1 / 0xA0，未说明其读写位或地址映射口径；接入前应确认 EEPROM 的独立寻址方式，以及全部器件的 7bit / 8bit 地址口径、双传感器寻址和 SerDes 映射。同步时序、复位与初始化顺序请使用配套配置。

### 双目标定与参数读取

出厂提供双目摄像头内参、外参及 IMU 内参、外参标定。双目标定采用 **Omni-Radtan** 模型，调用参数时必须匹配该模型。参数读取可使用 SENSING sgMIX，或按《双目相机 OTP 数据格式定义（对外版）》解析。

请使用当前设备的出厂标定值。机械设计外参只描述设计位置，不应替代当前设备的标定结果；旧款 S56 / S56C / S36 的标定参数也不能直接复用。

## 摄像头使用 {#平台接入}

### 与客户自研平台集成

1. 核对 GMSL2 6Gbps 解串器、连接器选项、供电和 I2C 地址映射，获取本型号的初始化与同步配置。
2. 初始化 SerDes 链路，按每目输出配置主机采集端（1920(H) × 1536(V) @ 30fps 或 1920(H) × 1080(V) @ 60fps，YUV422 8bit），并按配套配置设置帧同步。
3. 验证左右目顺序、图像方向、帧同步和 IMU 数据，读取当前设备的标定参数。
